# Shorty
Сервис сокращения ссылок — инструмент, который превращает длинные и громоздкие URL-адреса в компактные, удобные для копирования и пересылки.

## Stack
- Python
- FastAPI
- PostgreSQL
- SQLModel
- Alembic
- Docker
- Docker-compose
- Nginx
- Redis

## Установка
1. Установите Docker
2. Клонируйте репозиторий:<br>
`git clone https://github.com/akimov246/shorty.git`

## Конфигурация
Переменные окружения и основные настройки хранятся в файле `.env`

## Запуск
1. Перейдите в папку с проектом
2. Выполните команду:<br>
    ```docker compose up -d --build```

## Остановка
1. Перейдите в папку с проектом
2. Выполните команду:<br>
    ```docker compose down```
3. После остановки контейнеров, данные в postgres и redis остаются

## Использование
- Перейдите в браузере по адресу <a href="http://localhost">http://localhost</a>
- Вставьте любой URL в форму ввода и нажмите кнопку *Shorten*
- Получите короткий URL. Скопируйте полученную ссылку и вставьте ее в адресную строку.

## Возможности
- Генерация коротких URL
- Rate Limiter (ограничитель частоты запросов) — механизм, который контролирует, как часто пользователь может обращаться к API за определенный промежуток времени
- Для удобства управления базой данных ссылок, была добавлена админ панель. Попасть в нее можно по пути <a href="http://localhost/admin">http://localhost/admin</a>
